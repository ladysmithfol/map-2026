# Ladysmith Light Up Map 2026

Interactive map for the Ladysmith Festival of Lights **Light Up Night** — Thursday, November 26, 2026.

Tap or click a numbered food truck spot or a blue dot (local food establishments that may be open) for details and links.

Live site: https://map.ladysmithfol.com

Built from the Festival's Light Up Map. Static HTML/CSS/JS — no build step.
